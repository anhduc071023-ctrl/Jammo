# Sixs Unity Developer Test

A Unity game development test project featuring a top-down soccer scene with a controllable Jammo character, physics-based ball kicking, goal detection, and camera tracking.

## Overview

The player controls Jammo on a soccer field and kicks balls toward the goals. The project demonstrates gameplay programming, physics interactions, UI integration, camera behavior, and visual effects using Unity and C#.

## Features

- **Player Controller:** Move Jammo using keyboard input.
- **Player Animation:** Idle and run animations.
- **Ball Physics:** Rigidbody-based movement and kicking.
- **Kick System:** Manual Kick and Auto Kick functionality.
- **Goal Detection:** Detect when a ball enters a goal.
- **Visual Effects:** Confetti and star effects when scoring.
- **Camera Controller:** Top-down camera that follows the ball after a kick and returns to the player after scoring.
- **UI Controls:** Kick, Auto Kick, Reset, and Exit buttons.
- **Auto Kick Cooldown:** Prevent repeated activations through a cooldown.
- **Responsive UI:** Canvas scaling and anchors for different screen resolutions.

## Technologies

- Unity
- C#
- Unity Animator
- Rigidbody and Collider
- Unity UI
- Particle System

## Getting Started

1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Open the main gameplay scene.
4. Press **Play** in the Unity Editor.

## Controls

| Input | Action |
|---|---|
| WASD | Move Jammo |
| Kick button | Kick a ball toward a goal |
| Auto Kick button | Automatically kick the farthest available ball toward its nearest goal |
| Reset button | Restart the current scene |
| Exit button | Exit the application in a standalone build |

## Project Structure

The project includes scripts for player movement, ball physics, goal detection, camera control, automatic kicking, and UI interactions.

## Notes

This repository was created as part of a Unity game developer test. Some features and controls may depend on the current project configuration.
